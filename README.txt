SATYAM KUMAR — PORTFOLIO

Files:
- index.html: main page
- style.css: responsive dark navy/cyan styling
- script.js: mobile navigation, scroll reveal, rotating hero text
- assets/profile.jpg: supplied profile photo, cropped for the website
- resume.pdf: matching one-page resume

How to run:
1. Extract this ZIP.
2. Open the folder in PyCharm.
3. Open index.html in a browser, or use PyCharm's browser preview.
4. Keep the assets folder and all files in the same folder structure.
5. Upload the whole folder to a static host to publish it.

Before publishing:
- Verify every project repository and description.
- Add a public email/contact method if you want one.
- Update any experience dates/details if they change.
- The resume uses no phone number or email because none was provided.
